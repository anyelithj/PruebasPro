## Decisiones

- **Nivel MCER:** «sin clasificar» (`level: null`). No hay listas de vocabulario por nivel con una fuente fiable; no se estima.
- **Uno a la vez:** las descargas de libros pasan por una cola global del proceso, y si el mismo libro se pide dos veces a la vez, se hace una sola descarga. Con varias réplicas de NestJS habría que pasar a un candado en Redis.
- **Origen del texto:** solo `gutenberg.org` (evita SSRF si la instancia de Gutendex no es de fiar). Tope de 20 MB por libro.
- **RAG:** se indexarán solo las palabras que el usuario marque para aprender (evento `WordMarkedToLearn`), nunca los libros.
