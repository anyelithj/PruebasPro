# Sistema de diseño: Tailwind CSS 4 + `@aula/ui-tokens`

`src/app/globals.css` es la única hoja de estilos: importa Tailwind, los tokens compartidos y define las **utilidades del sistema**
con `@utility`. Angular importa la misma hoja, así que las clases de esta página se ven igual en los dos frontends.

## Temas

Seis temas definidos en `@aula/ui-tokens/tailwind-preset` (`THEMES`). El tema es una clase en `<html>`; los colores son variables CSS,
por eso los componentes nunca escriben un color a mano.

| Clase       | Icono | Dónde se ofrece                      |
| ----------- | ----- | ------------------------------------ |
| `light`     | ☀     | Portal y páginas públicas (por defecto) |
| `dark`      | 🌙    | Portal y páginas públicas            |
| `sepia`     | 📜    | Portal                               |
| `hcontrast` | ⚡    | Portal                               |
| `deepfocus` | 🎯    | Portal                               |
| `vr`        | 🥽    | Portal                               |

Las páginas públicas solo admiten `PUBLIC_THEMES` (Claro y Oscuro); con otro tema guardado se muestran en Claro.

## Reglas

1. Un componente usa las **utilidades** (`btn`, `control`, `chip`, `surface`, `title-*`) antes que una lista larga de clases sueltas.
2. Los colores salen de los tokens (`bg-background`, `text-foreground`, `text-tone-brand`…), nunca hexadecimales en el componente.
3. Responsive con los breakpoints de Tailwind (`sm`, `md`, `lg`), diseñando primero para móvil.
4. Las animaciones respetan **movimiento reducido** (`motion.css` de `@aula/ui-tokens`).
