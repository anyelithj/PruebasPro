# Sistema de diseño compartido con Next.js

`src/styles.css` importa `apps/frontend-next/src/app/globals.css`: **una sola hoja** (Tailwind CSS 4 + `@aula/ui-tokens`) para los dos
frontends. Los temas, colores, escala tipográfica y utilidades son los mismos; por eso una pantalla Angular dentro del shell Next.js
no se distingue del resto del portal.

## Temas

`core/theme` lee `THEMES` de `@aula/ui-tokens/tailwind-preset` y pone la clase en `<html>`:
`light` ☀ · `dark` 🌙 · `sepia` 📜 · `hcontrast` ⚡ · `deepfocus` 🎯 · `vr` 🥽.
Los componentes usan variables de color (`bg-background`, `text-foreground`, `text-tone-brand`…), nunca hexadecimales.

## Convenciones

1. Plantillas y estilos en línea con Tailwind; las **utilidades** (`btn`, `control`, `chip`, `surface`) antes que clases sueltas.
2. Nombres en kebab-case e inglés con sufijo de rol: `.component.ts`, `.page.ts`, `.facade.ts`, `.element.ts`, `.template.ts`.
3. Responsive con los breakpoints de Tailwind, primero móvil (por ejemplo `two-column` apila columnas por debajo de `md`).
4. Movimiento reducido respetado por `motion.css` de `@aula/ui-tokens`.
